# Тестовые сценарии

## Сценарий 1. Базовый рабочий процесс

Мини-программа: `tests/scenarios/scenario_basic_workflow.cpp`.

Шаги:

1. Создать задачу.
2. Запустить таймер по задаче.
3. Остановить таймер.
4. Проверить, что рабочая сессия создана и завершена.

Ожидаемый результат: программа выводит `Basic workflow passed`.

## Сценарий 2. Сохранение и загрузка данных

Мини-программа: `tests/scenarios/scenario_persistence.cpp`.

Шаги:

1. Создать временный каталог данных.
2. Сохранить задачу и завершенную рабочую сессию.
3. Загрузить данные повторно.
4. Проверить количество объектов и длительность сессии.

Ожидаемый результат: программа выводит `Persistence scenario passed`.

## Сценарий 3. Формирование отчета

Мини-программа: `tests/scenarios/scenario_reporting.cpp`.

Шаги:

1. Создать две задачи.
2. Создать завершенные сессии по каждой задаче.
3. Рассчитать суммарное время через `ReportService`.
4. Напечатать отчет.

Ожидаемый результат: программа выводит отчет и строку `Reporting scenario passed`.

## Unit-тесты

Unit-тесты находятся в каталоге `tests/`:

- `test_task.cpp` - проверка статусов и модели задачи.
- `test_time_session.cpp` - проверка расчета длительности сессии.
- `test_task_manager.cpp` - создание, поиск, архивирование и загрузка задач.
- `test_time_tracker.cpp` - запуск и остановка таймера, запрет второй активной сессии.
- `test_storage.cpp` - сохранение и загрузка задач и сессий.
- `test_report_service.cpp` - агрегация времени и вывод отчета.
- `test_console_ui.cpp` - сценарии работы через консольное меню.
