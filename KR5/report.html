Контейнеризация

Дисциплина: Программирование корпоративных систем

Проект: Тайм-трекер

Технологии: C++17, CMake, Catch2, Docker

Семестр: 2 семестр, 2025-2026 гг.

Цель работы

Цель практического занятия - изучить основы контейнеризации и подготовить Docker-образ, в котором учебный C++ проект собирается, тестируется и запускается в чистом Linux-окружении.

Краткое описание проекта

В качестве учебного проекта используется консольный тайм-трекер. Приложение позволяет создавать задачи, запускать и останавливать таймер, просматривать историю рабочих сессий и формировать отчет по затраченному времени.

Выполненные изменения

  • Создан каталог KR5 на основе версии проекта с unit-тестами.
  • Добавлен многостадийный Dockerfile.
  • Добавлен файл .dockerignore для исключения временных файлов.
  • В src/main.cpp добавлен режим запуска через аргументы командной строки.
  • Сборка Docker-образа выполняет unit-тесты Catch2 через ctest.
  • Финальный контейнер запускает приложение командой time_tracker.

Структура Dockerfile

Этап Назначение
build Устанавливает зависимости сборки, копирует исходный код, запускает CMake, компилирует проект и выполняет тесты.
runtime Создает чистое окружение для запуска, копирует только готовый исполняемый файл и запускает приложение от отдельного пользователя.

Команды сборки и запуска

Сборка образа выполняется из каталога KR5:

docker build -t time-tracker-kr5 .

Демонстрационный запуск контейнера:

docker run --rm time-tracker-kr5

Передача аргументов командной строки:

docker run --rm time-tracker-kr5 --help
docker run --rm time-tracker-kr5 add-task "Write report" "Prepare Docker section"
docker run --rm time-tracker-kr5 list-tasks
docker run --rm time-tracker-kr5 report

Запуск тестов внутри контейнера

Тесты запускаются на этапе сборки образа командой: 

ctest --test-dir build --output-on-failure

Если хотя бы один тест завершится ошибкой, команда docker build также завершится ошибкой, и runtime-образ не будет создан.

Хранение данных

По умолчанию приложение хранит CSV-файлы в каталоге /app/data. Для сохранения данных между запусками контейнера можно подключить Docker volume: 

docker volume create time-tracker-data
docker run --rm -v time-tracker-data:/app/data time-tracker-kr5 add-task "Docker demo"
docker run --rm -v time-tracker-data:/app/data time-tracker-kr5 list-tasks

Вывод

В результате работы проект был подготовлен к запуску в Docker. Контейнер обеспечивает чистое Linux-окружение, устанавливает все зависимости явно, собирает приложение без ручной настройки, запускает тесты Catch2 и предоставляет готовый исполняемый образ для демонстрации основной функции тайм-трекера.
