# Практическое занятие №2

Выбранная тема: **Тайм-трекер (учет рабочего времени)**.

Почему выбрана эта тема:

- простая предметная область;
- не нужны сеть, GUI, внешние API и сложные алгоритмы;
- требования легко формализуются через пользовательские сценарии;
- можно реализовать как консольное C++ приложение с хранением данных в файлах.

## Файлы

- `requirements.md` - сбор и классификация требований по Вигерсу.
- `srs.md` - SRS-документация проекта.
- `report.html` - оформленная версия с титульным листом и UML-диаграммами.
- `report.pdf` - PDF-версия, если генерация через Edge прошла успешно.
