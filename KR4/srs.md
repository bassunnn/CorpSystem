# Отчет по тестированию проекта "Тайм-трекер"

ФИО студента: Лобин Александр Ильич

Номер группы: ЭФБО-06-24

## 1. Цель

Разработать систему unit-тестов и тестовых сценариев для консольного C++ проекта "Тайм-трекер".

## 2. Используемая библиотека

Для тестирования используется Catch2. Библиотека подключается через `FetchContent` в `tests/CMakeLists.txt`.

## 3. Unit-тесты

- `test_task.cpp` - тесты модели задачи и статусов.
- `test_time_session.cpp` - тесты расчета длительности сессии.
- `test_task_manager.cpp` - тесты создания, поиска и архивирования задач.
- `test_time_tracker.cpp` - тесты запуска и остановки таймера.
- `test_storage.cpp` - тесты сохранения и загрузки данных.
- `test_report_service.cpp` - тесты формирования отчета.
- `test_console_ui.cpp` - тесты пользовательских команд через консольное меню.

## 4. Сценарные мини-программы

- `scenario_basic_workflow.cpp` - создание задачи, запуск и остановка таймера.
- `scenario_persistence.cpp` - сохранение и повторная загрузка данных.
- `scenario_reporting.cpp` - расчет и вывод отчета.

## 5. Команды

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```
