## 1. Описание проекта

Тайм-трекер - консольное приложение на C++ для учета рабочего времени по задачам. Пользователь может создавать задачи, запускать и останавливать таймер, просматривать историю рабочих сессий и получать отчет о суммарном времени.

## 2. Применимые паттерны проектирования

### Facade

Паттерн применим к классу `ConsoleUI`. Он предоставляет пользователю простое меню и скрывает взаимодействие с подсистемами `TaskManager`, `TimeTracker`, `Storage` и `ReportService`.

### Repository

Паттерн применим к классу `Storage`. Он отделяет бизнес-логику от деталей хранения данных в файлах `tasks.csv` и `sessions.csv`.

### Singleton

Паттерн может быть применен к будущему классу `AppConfig`, который будет хранить путь к данным и глобальные настройки приложения. В текущей версии Singleton не добавлен, потому что зависимости удобно передаются через конструкторы.

### Strategy

Паттерн применим к будущим вариантам формирования отчетов: ежедневный отчет, отчет по задаче, отчет за период. Для этого можно выделить интерфейс `ReportStrategy`.

### Command

Паттерн применим к пунктам меню консольного интерфейса. Действия `addTask`, `startTimer`, `stopTimer` можно оформить отдельными командами с методом `execute()`.

### Factory Method

Паттерн применим к созданию объектов `TimeSession` и отчетов. Фабрика сможет централизованно задавать идентификатор, время начала и дополнительные параметры.

## 3. Система сборки

Проект разделен на каталоги `include/` и `src/`. Сборка выполняется через CMake:

```sh
cmake -S . -B build
cmake --build build
cd build
./time_tracker
```

Сторонние библиотеки не используются.
